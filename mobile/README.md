# Mobile (Flutter) - حساب‌یار هوشمند تنخواه

## پیش‌نیاز
- Flutter SDK نصب‌شده (`flutter doctor` باید سبز باشد)
- Android SDK / یک دستگاه یا Emulator اندروید

## نصب پکیج‌ها
```bash
cd mobile
flutter pub get
```

## اجرا روی Emulator/دستگاه برای توسعه
```bash
flutter run
```
> نکته: در Emulator اندروید، آدرس پیش‌فرض Backend روی `http://10.0.2.2:8000` تنظیم شده
> (که به `localhost` روی ماشین میزبان اشاره می‌کند). این را می‌توانید در صفحه «تنظیمات» عوض کنید.

## ساخت APK نهایی (Release)
```bash
flutter build apk --release
```
فایل خروجی اینجا ساخته می‌شود:
```
build/app/outputs/flutter-apk/app-release.apk
```
این فایل را می‌توانید مستقیماً روی گوشی اندروید نصب کنید (نیاز به فعال‌سازی «نصب از منابع ناشناس» دارید).

## فونت فارسی
برای نمایش صحیح فارسی، فونت Vazirmatn (یا فونت دلخواه) را در `assets/fonts/` قرار دهید
و در `pubspec.yaml` بخش fonts را از حالت کامنت خارج کنید.

## وضعیت فعلی این اسکلت
این پروژه یک MVP کارکردی است، نه یک اپلیکیشن تجاری کامل. صفحات اصلی و مسیر
Voice → STT → AI → Confirmation → Accounting Engine پیاده‌سازی شده‌اند. موارد زیر
هنوز باید تکمیل شوند (در بخش «ادامه کار» فایل README اصلی پروژه توضیح داده شده):
- افزودن `flutter_localizations` برای RTL کامل ویجت‌های سیستمی (تاریخ‌پیکر و ...)
- افزودن منطق واقعی Backup/Restore و ورود با PIN/Biometric (دکمه‌ها آماده‌اند، منطق پیاده نشده)
- افزودن اندپوینت‌های categories CRUD و اتصال کامل صفحه دسته‌بندی‌ها به بک‌اند
- افزودن خروجی Excel/PDF/CSV در گزارش‌ها
